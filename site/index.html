Standard Fabric. Nothing hidden.

Anti-cheats look for injected code and packets a vanilla client would never send. DuskClient does neither, and the source is there for anyone to read.

Read the client code

  • No injection

    No JVM agents, no runtime injection, no rewritten jars. DuskClient loads through the stock Fabric loader like any other mod.

  • Client side only

    Its mixins touch rendering, the HUD and input. Nothing sends packets to the server or changes movement.

  • Verified files

    Every game file is checked against Mojang's sha1 hash before launch, so what runs is what Mojang shipped.

  • Signed updates

    The launcher checks for updates at startup and every six hours, and only installs builds signed with our key.

Questions

Is it really free?

Yes. The launcher and the client are free, and there are no ads, ever. Cosmetics use coins, which you get from redeem codes and from inviting friends: 500 coins for you and 250 for them.

Can I get banned for using DuskClient?

DuskClient only changes what you see: the HUD, rendering, and input like Toggle Sprint. It never sends packets or touches movement, which is what anti-cheats watch for. Every server still sets its own rules, so check the ones you play on.

Which Minecraft versions work?

Vanilla and Fabric for every release from 1.21 to 26.3, and NeoForge from 1.20.2. DuskClient has builds for 1.21.1, 1.21.3, 1.21.4, 1.21.5, 1.21.8, 1.21.10, 1.21.11, 26.1, 26.2 and 26.3.

Do I need a Microsoft account?

Yes. Sign in with the Microsoft account that owns Minecraft: Java Edition.

Can I add my own mods?

Yes. Fabric instances take any Fabric mods, installed from Modrinth or dropped in by hand. DuskClient sits next to them.

macOS says the app is damaged or can't be opened.

That's Gatekeeper, because the build isn't notarized yet. Install with Homebrew, or right-click the app and choose Open. If that doesn't work, run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/DuskLauncher.app
How do updates work?

The launcher checks at startup and every six hours. When a signed update is ready, an update button appears in the top bar. Nothing installs until you click it.

Can I read the code?

Yes. The launcher, the client mod and the cosmetics server are all on GitHub. Bug reports go to Issues.
