# DuskLauncher Design System

This document is the source of truth for the launcher's visual language and
rendering architecture. The reference aesthetic is Dawn Launcher's pixel-art
UI (competitive analysis in `RESEARCH.md`), adapted for DuskLauncher with
one rule: **every visible element does something real — no ads, no dead
chrome, ever.**

## Brand

- Wordmark: **DUSK**LAUNCHER — gold (`#FFD000`) Monocraft Bold, "DUSK" gold +
  "LAUNCHER" white, hard 3px drop shadow, 4-point sparkle mark.
- Mascot: the "dusk knight" — a full-helm character with a glowing red visor
  (original art, generated by `launcher/scripts/gen-art.mjs`; never copy
  Mojang assets).

## Themes

One dark-panel base for both themes; the theme swaps the scene palette and
the accent family. Tokens live in `launcher/src/design/tokens.css`.

| | Nether (default) | Overworld |
|---|---|---|
| Scene | maroon sky, crimson diamond sun, lava sea, netherrack-ish silhouettes, rising embers, pale "wisps" | pastel blue sky, golden sun, sea shimmer, grass terrain, drifting pollen, golden flyers |
| Accent | `#FF1E43` crimson (PLAY border, active tabs, links) | `#FFD000` gold (PLAY border gold per reference) |
| Panels | `#121212`–`#1A1A1A` charcoal, glass overlays | slightly lifted blue-charcoal, gold accents |

Success/active-state green: `#39D353` in both themes.

## Pixel idiom

- 2px solid borders, **hard shadows only** (zero blur — `4px 4px 0 rgba(0,0,0,.55)`),
  near-zero radii, notched corners (`.pixel-notch` clip-path).
- Headings/tabs/CTAs: Monocraft (SIL OFL, bundled). Body/metadata: Inter (bundled).
  No webfont CDNs — the launcher works offline.
- `image-rendering: pixelated` on every canvas/img; icons are hand-drawn pixel
  grids (`PixelIcon.tsx`) rendered as crisp SVG rects — no icon font, no emoji.
- Buttons "press" by translating 2px and dropping their shadow (steps easing).

## Screens

- **Home** — animated scene behind; centered live 3D player (skinview3d) with
  username tag + `CLICK FOR WARDROBE`; action console = PLAY NOW (subtext =
  selected profile) + quick-profile popout (≡) + QUICK JOIN card (profile
  server, one-click join); audio widget (mute + slider) top right; launch
  progress panel replaces the console while installing.
- **Profiles** — NEW PROFILE (red outline), filter tabs ALL/VANILLA/FABRIC,
  count, search; card grid with procedural per-profile pixel banner (seeded
  from the profile id), avatar, metadata (loader • version • last played •
  mods), PLAY NOW + ⚙ per-profile settings (name, resolution, server, JVM
  args, memory quick-set); DELETE with confirm.
- **Mods (Modpacks)** — left filter sidebar (category/version/loader with
  pixel checkboxes), sort + page-size + result count + pager; entry cards
  (icon, title+author, description, downloads/follows/updated, loader pills)
  with green one-click INSTALL → creates a pinned profile and downloads all
  files via Modrinth.
- **Skins** — grid (ADD SKIN tile, current skin with green CURRENT badge,
  cheap 2D paper-doll previews) + right 3D inspector with −/+ zoom,
  CANCEL / APPLY SKIN (apply disabled until Microsoft login lands — honest
  tooltip, never a dead button without explanation).
- **Settings** — icon tab strip: General (theme, motion, scene FPS, sound),
  Java & Memory (memory slider + JVM args + per-major Java runtime overrides
  with Browse + env vars + prelaunch/wrapper/post-exit hooks), Display
  (default resolution), Files (data dir reveal), Debug (versions, EXPORT DEBUG).
- **Accounts modal** — active card (avatar, IGN, honest offline-session note),
  gold ADD ACCOUNT (surfaces the Azure-registration dependency until wired).
- **Footer** — expandable **launch console** (streamed game-log) + ONLINE pill.
  Replaces Dawn's leaderboard with something a launcher actually needs.

## Rendering & performance architecture

Beauty without stealing CPU/RAM from the game itself:

1. **Low-res canvas + pixelated upscale.** The scene renders at ~480px internal
   width (`src/background/scene.ts`) and CSS upscales it with
   `image-rendering: pixelated`. GPU load is trivial by construction.
2. **Pre-rendered layers.** Sky bands + motes, cloud strips, terrain
   silhouettes (tileable: column heights from integer-frequency sines), and
   sea band rows are drawn once per size/theme to offscreen canvases. A frame
   is integer-aligned blits plus a small particle update — no per-frame
   procedural terrain, no allocations.
3. **Frame governor** (`src/lib/fps.ts`): one rAF loop per animated surface,
   capped at 30 FPS (user-selectable 30/60/static), fully halted on
   `visibilitychange`, while the game is running, and under reduce-motion.
4. **3D player** (skinview3d + three.js): pauses via `renderPaused` under the
   same conditions; disposes when its view unmounts.
5. **GPU-friendly CSS**: animations use transform/opacity only (steps()
   easing for pixel feel); vignette/glow overlays are pure CSS.
6. **Events**: launch progress is throttled to ~15 emits/s; game logs stream
   in batches (~120 ms); the UI log is a ring buffer (400 lines).

## Legal note

All artwork (scene, sprites, default skin, icons, fonts) is original,
bundled, or OFL-licensed. Minecraft/Mojang assets are never extracted or
redistributed; the game is launched through the standard Fabric/vanilla
pipeline (see `ARCHITECTURE.md` anti-cheat stance).
